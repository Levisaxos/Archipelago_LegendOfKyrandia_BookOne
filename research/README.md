# research/

Extracted and derived data from the game / engine — the raw material for the
randomizer logic.

| File | What it is |
|------|-----------|
| `kyra1_item_ids.txt` | Authoritative engine item list, IDs 0–106 (the `k1ItemNames` table extracted from `scummvm.exe`; matches the debugger `give` command). |
| `kyra1_items.json` | Engine-ID ↔ AP-ID crosswalk (top-level `items`), generated by `pyscripts/build_item_crosswalk.py`. |
| `walkthrough_findings.md` | **Authoritative** quest chain from the GameFAQs guide (2026-06-18) + a punch-list of corrections to the DRAFT model. Supersedes `walkthrough.md` on any conflict. |
| `walkthrough.md` | Earlier memory-based quest chain + the **check taxonomy**. Partly superseded — see `walkthrough_findings.md` for corrected facts. |
| `logic.md` | Abstract region graph + access rules (DRAFT v2). Generated context for `data.py`. |
| `flags.md` | Game-flag legend from `setGameFlag` instrumentation — candidate keys for event locations. |
| `hazards.md` | Softlocks / inventory wipes / missables and how apworld + engine fork handle them. |
| `engine_hooks.md` | C++ function / EMC-opcode locations the AP fork hooks or reuses (poof/drop respawn primitive, birthstone table, grant/flag hooks). Read-only reference for the build-blocked engine work. |
| `locations.json` | Machine-readable location/edge dump, generated from `apworld/kyrandia/data.py`. |

Verified engine IDs (live `give`-tested): Amethyst=1, Emerald=4, Topaz=10,
Fallen Star=50. Derived: Ruby=6, Teardrop=52.
